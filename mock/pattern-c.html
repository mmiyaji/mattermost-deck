Mattermost Web の右側に、メンション・チャンネル・DM・検索結果を並べるペインを追加します。

ログイン、投稿、編集、スレッド操作は Mattermost 本体のままです。Deck が足すのは読むための一覧だけで、Mattermost の設定やチーム構成は変更しません。

05

通信と保存

RESTいまブラウザーで開いている Mattermost のセッションをそのまま使います。Deck のための追加ログインはありません。
WebSocketPersonal Access Token を設定したときだけ有効です。未設定の場合は定期取得で更新します。
PAT の保存 既定は chrome.storage.session。永続保存は明示的に選んだときだけで、クライアント側で暗号化します。 Defaults to chrome.storage.session. Persistent storage happens only when you choose it, and is encrypted client-side.
有効化の条件設定した origin と一致、許可した route kind に合致、任意のチーム slug 制限を満たす、health-check API が成功する。すべて満たしたときだけ描画します。
保存されるもの設定、レイアウト、お気に入り、要確認の状態、除外設定。すべてこのブラウザー内に、サーバーとアカウントごとに保存します。
送信先設定した Mattermost サーバー以外へは送りません。第三者の analytics も広告もありません。

STEP 1Chrome ウェブストアから追加

インストールすると Options 画面が開きます。

STEP 2Mattermost Server URL を保存

その origin への Chrome 権限が要求されます。リモートは HTTPS が必要です。

右側に Deck が出たら ＋ から追加します。

07

操作のヒント

  1. 01 ペインのタイトルをダブルクリック、右クリック、または F2 で別名を付けられます。空欄のまま保存すると元の名前に戻ります。 Rename a pane by double-clicking its title, right-clicking it, or pressing F2. Save it blank to restore the original name.
  2. 02 タイトルのドラッグ中に Esc で並び替えを取り消します。投稿も検索条件もスクロール位置もそのままです。 Press Esc while dragging a title to cancel the move. Posts, filters, and scroll positions all stay as they were.
  3. 03 上下の境界をダブルクリック、または Home で高さを均等に戻します。↑ ↓ でも調整できます。 Double-click the divider between rows, or press Home, to even out their heights. ↑ and ↓ adjust it too.
  4. 04 ペイン右端の境界をダブルクリック、または Home で既定幅に戻します。← → でも調整できます。 Double-click a pane's right edge, or press Home, to return it to the default width. ← and → adjust it too.
  5. 05 ペインの虫眼鏡で、読み込み済みの本文と投稿者を絞り込めます。追加の通信はなく、日本語入力の変換中も一覧が消えません。 The magnifier in each pane filters the posts and authors already loaded. It sends no extra requests, and the list stays put while an IME conversion is in progress.
  6. 06 使い分けが複数あるときは Views に保存します。端末を移すときは JSON で書き出します。 Save each way you work as a View. Export to JSON when you move to another machine.
  7. 07 Appearance のコンパクト表示で 時刻 投稿者: 本文 の 1 行表示になります。 Compact mode under Appearance switches rows to a single line: time author: message.
  8. 08 投稿の「…」から、そのユーザーの投稿やその会話を表示しないよう設定できます。取得や既読には影響しません。 The “…” menu on a post hides that author or that conversation. It changes nothing about fetching or read state.
08

よくある質問

Mattermost の代わりに使うものですか

いいえ。ログイン、投稿、編集、スレッド操作は Mattermost 本体のままです。

Personal Access Token は必要ですか

必要ありません。未設定でも定期取得で更新します。設定すると WebSocket によるリアルタイム更新になります。

どのサーバーでも自動的に動きますか

いいえ。Options に保存して Chrome の origin 権限を許可したサーバーだけです。リモートには HTTPS が必要です。

データは開発者のサーバーへ送られますか

送られません。通信するのは設定済みの Mattermost サーバーだけです。

Deck で読むと Mattermost 側も既読になりますか

なりません。「確認済みにする」も Mattermost の既読とは別の状態です。

Mattermost Free Edition でも使えますか

ブラウザーから Mattermost Web と必要な API にアクセスできれば使えます。グループメンションなど一部はサーバーのライセンスと設定次第です。

拡張機能を削除するとどうなりますか

このブラウザーに保存していた設定、レイアウト、お気に入り、要確認の状態、除外設定も一緒に消えます。

不具合の報告はどこへ

GitHub Issues で受け付けています。
