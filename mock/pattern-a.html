Mattermost Deck

Mattermost Web の右側に、メンション・チャンネル・DM・検索結果を並べるペインを追加する Chrome 拡張です。ログイン、投稿、編集、スレッド操作は Mattermost 本体をそのまま使います。

MIT LicenseUI 9言語Chrome 120 以降第三者トラッキングなし

これは何か

Mattermost には複数のチームとチャンネルがありますが、一度に見えるのは 1 つのチャンネルだけです。Deck は閲覧用のペインを右側に足して、別のチャンネルや自分宛のメンションを開いたまま並べられるようにします。

Deck は Mattermost を置き換えません。ページに Shadow DOM の右レールを差し込むだけで、投稿も編集もスレッドの操作も Mattermost 本体の画面で行います。

拡張が描画するのは、設定した origin と一致し、許可した route kind に合致し、任意のチーム slug 制限を満たし、health-check API が成功したときだけです。それ以外のサイトでは何も挿入しません。

ペインの種類

メンション参加している全チーム・全チャンネルのメンションを 1 つの一覧にまとめます。カスタムメンションキー、@all @channel @here、グループメンション、DM と GM、CRT 有効時のスレッド返信を Mattermost の設定どおりに判定します。
要確認メンション「確認済みにする」を押すまで消えない一覧です。Mattermost 側で既読にしても、投稿を開いても消えません。
チャンネル監視特定のチャンネルを開いたままにします。
DM 監視DM とグループメッセージを個別のペインとして常時表示します。
検索検索結果をペインとして固定します。ハイライトキーワード設定と組み合わせて使います。
お気に入り投稿の ☆ で登録する個人用のリストです。Mattermost の保存済み投稿や共有ピン留めとは別枠で、サーバーとアカウントごとに最大 100 件をこのブラウザーに保存します。
保存済み投稿Mattermost の保存済み投稿を一覧にします。
Diagnostics接続状態と同期の様子を表示します。Performance タブには API の件数・平均遅延・P95・エラー率、直近のトレース、JSONL 書き出しがあります。

画面の並べ方

既定は横一列です。「ビュー」から上下 2 段に切り替えられます。上段と下段はそれぞれ独立して左右にスクロールし、境界をドラッグすると高さの配分を 20〜80% の範囲で変えられます。

幅ペインごとに 260〜480px。右端の境界をドラッグします。
並び替えタイトルをドラッグします。上下の段をまたいで移動でき、点線枠で移動先を確認してから離します。
別名タイトルをダブルクリック、右クリック、または F2。空欄のまま保存すると元の名前に戻ります。
保存ペインの組み合わせを Views に保存できます。JSON で書き出し・読み込みもできます。

Mattermost の右ペインを開いたとき

スレッド、検索結果、ピン留め投稿などの右ペインを開くと、その実測幅の分だけ Deck が同じフレームで縮み、メイン表示の幅は開く前のまま保たれます。Deck の残り幅が 280px を下回る場合は 52px まで折り畳み、右ペインを閉じると指定の幅とスクロール位置に戻ります。

メンションの扱い

要確認メンション

メンションペインの操作欄から「要確認タブを複製」を選ぶと、元のペインを残したまま、同じ対象チームの要確認ペインを隣に作ります。「要確認モードに変更」はタブを増やさず、そのペインの対象チーム・名前・位置を保ったまま切り替えます。

各投稿の「確認済みにする」で一覧から外れます。直後の 5 秒間は「確認済みにしました　取り消す」が出て、その場で戻せます。表示が消えた後も、操作欄の確認済み履歴から未確認に戻せます。

表示の除外

投稿にマウスを重ねると出る「…」から、そのユーザーの投稿、またはその会話を表示しないよう設定できます。会話の除外は親投稿と今後増える返信にも適用されます。通常メンションと要確認メンションで同じ設定を共有します。

除外は表示だけに効きます。投稿の取得、Mattermost 本体の通知、既読や確認済みの状態は変わりません。

通信と保存

RESTいまブラウザーで開いている Mattermost のセッションをそのまま使います。Deck のための追加ログインはありません。
WebSocketPersonal Access Token を設定したときだけ有効になります。未設定の場合は定期取得で更新します。
PAT の保存先既定は chrome.storage.session です。永続保存は明示的に選んだときだけで、その場合はクライアント側で暗号化します。
保存されるもの設定、レイアウト、お気に入り、要確認の状態、除外設定。すべてこのブラウザー内に、サーバーとアカウントごとに保存します。
送信先設定した Mattermost サーバー以外へは送りません。開発者が運用するサーバーも、第三者の計測もありません。

導入手順

  1. Chrome ウェブストアから追加するインストールすると Options 画面が開きます。
  2. Connection に Mattermost Server URL を保存する保存すると、その origin に対する Chrome の権限が要求されます。リモートサーバーには HTTPS が必要です。
  3. Mattermost を開いてペインを足す右側に Deck が出たら ＋ から必要なペインを追加します。

Team Slug の制限、PAT、テーマ、幅、プロファイルは、必要になったときに追加で設定します。

操作のヒント

  1. ペインのタイトルをダブルクリック、右クリック、または F2 で別名を付けられます。空欄のまま保存すると元の名前に戻ります。
  2. タイトルのドラッグ中に Esc を押すと並び替えを取り消します。投稿も検索条件もスクロール位置もそのままです。
  3. 上下 2 段の境界をダブルクリック、または Home で高さを均等に戻します。↑ ↓ でも調整できます。
  4. ペイン右端の境界をダブルクリック、または Home で既定幅に戻します。← → でも調整できます。
  5. ペインの虫眼鏡で、読み込み済みの本文と投稿者を絞り込めます。追加の通信はなく、日本語入力の変換中も一覧が消えません。Esc で閉じます。
  6. 運用用とサポート用のように使い分けが複数あるときは、ペインの組み合わせを Views に保存します。端末を移すときは JSON で書き出します。
  7. 表示が詰まってきたら Appearance のコンパクト表示へ。カードをやめて 時刻 投稿者: 本文 の 1 行表示になります。
  8. どのペインがどのチームかわからなくなったら、ペイン識別カラーを付けると見分けやすくなります。

よくある質問

Mattermost の代わりに使うものですか

いいえ。ログイン、投稿、編集、スレッド操作は Mattermost 本体のままです。Deck は読むための一覧を右側に足すだけです。

Personal Access Token は必要ですか

必要ありません。未設定のままでも定期取得で更新します。設定すると WebSocket によるリアルタイム更新に切り替わります。

どのサーバーでも自動的に動きますか

いいえ。Options に保存して Chrome の origin 権限を許可した Mattermost サーバーだけで有効になります。リモートサーバーには HTTPS が必要です。

データは開発者のサーバーへ送られますか

送られません。拡張が通信するのは設定済みの Mattermost サーバーだけで、第三者の analytics や広告、プロファイリングはありません。

Deck で読むと Mattermost 側も既読になりますか

なりません。要確認メンションの「確認済みにする」も、Mattermost の既読とは別の状態です。

ウィンドウが狭いときはどうなりますか

Mattermost の右ペインを開くと、その実測幅の分だけ Deck が縮みます。残りが 280px 未満になる場合は 52px に折り畳み、右ペインを閉じると元の幅とスクロール位置に戻ります。

Mattermost Free Edition でも使えますか

ブラウザーから Mattermost Web と必要な API にアクセスできれば使えます。グループメンションなど一部の機能は、サーバーのライセンス・設定・権限で利用できる場合に限られます。

対応環境を教えてください

Google Chrome 120 以降です。Docker の E2E 全テストを Mattermost 9.5.4 で実行し、経路変更・チーム切り替え・スレッドレイアウト・レスポンシブ動作は 9.5.11、10.11.22、11.8.2 でもリリースごとに確認しています。
