# 本文キャッシュの削除・保持の検証（2026-11-03）

## 対象

永続メンション表示は既定で有効のまま。削除するのはメンション表示キャッシュ（IndexedDB・セッション）とお気に入り本文であり、**要確認メンションの保存済み本文・未確認／確認済み判断・投稿ID、お気に入り登録、設定は残す**。

- 設定画面から手動で全アカウントの本文キャッシュを削除できる。
- ログアウト・認証失効（401）では該当アカウントだけを削除する。文書遷移・Worker再起動後も拡張セッション内のタブ対応表を利用する。
- 投稿・チャンネル閲覧やチーム内投稿検索の403では対象アカウントを削除する。グループメンション等の機能利用権限の403とは区別する。
- 削除前に開始した取得による再保存を拒否し、削除後の正常取得は再保存できる。
- 期限切れの表示用キャッシュは操作時、起動／更新時、30分ごとのアラームで整理する。
- 永続保存を無効にして保存した場合は、Deckを開いていなくても全アカウントの永続メンション表示キャッシュを削除する。この切り替えではセッション表示・お気に入り本文は保持する。
- お気に入り登録の変更と旧形式本文の整理をWorkerの同じキー別キューで処理し、同時操作による登録情報の喪失を防ぐ。

## 限界

ブラウザー停止中に定期処理は実行されない。端末上の安全消去やアプリ独自の本文暗号化は行わない。利用者の指定により要確認投稿の本文は別管理で保持するため、「保存済み本文を削除」は拡張が持つ全投稿本文の消去ではない。正常な再取得後は有効なキャッシュ設定に従って本文が再保存される。
