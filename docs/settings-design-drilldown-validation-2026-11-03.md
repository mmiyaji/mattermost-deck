# 設定画面と失敗リクエスト詳細の検証（2026-11-03）

選択された1案目を既存の設定画面に反映。濃紺のヘッダー、白い設定面、淡いサイドナビ、設定行の区切りと保存フッターを揃えた。既存のプロフィール・保存・取り消し・多言語・ダークテーマを保持する。

## 外観プレビュー

- 外観タブだけの中央寄せオフセットを削除し、見出し位置を他のタブと統一。
- プレビューは設定したデッキ幅・ペイン幅・文字サイズの実寸を維持。枠外へページを押し広げず、プレビュー枠内で横スクロールする。
- 幅図・ペインをborder-boxに統一。2列・追従表示は十分な幅のある場合だけにする。
- 1400pxのデッキ幅、800pxのペイン幅、140%の文字サイズでも1440／900／390px画面に収まることを確認。

## パフォーマンス

- Recharts 3.10.1を採用。アニメーションを無効にし、直近20分を1分ごとの積み上げ棒で表示。
- 「失敗／全リクエスト」ボタンから失敗一覧へ移動。赤い棒からはその時間帯の失敗へ絞り込む。
- 時間・HTTPステータス・文字検索で絞り込み、各行でAPIパス、呼び出し元、所要時間、待ち時間、エラーを確認できる。
- 50件ごとのページ切替。HTTP応答のない通信失敗とHTTPエラーを区別し、未計測時間を0として扱わない。
- キーボードからのボタン起動・時間選択にも対応。グラフ選択と一覧は同じ正規化モデルを使う。
- 幅を狭めた際、非表示ツールチップの古い座標でページが広がる問題も修正。
