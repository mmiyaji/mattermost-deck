# 設定画面の配色・説明・フッター修正（2026-11-03）

ユーザーの画像で報告された問題を再現し、以下を修正した。

## 配色

`mattermost` テーマは設定画面では濃色へフォールバックするが、リクエスト表だけは `dark` と完全一致する場合以外に明色の文字色・入力色を使っていた。暗い背景に対する文字コントラストは約1.16だった。

表・フィルター・展開詳細・グラフの色を設定画面の共通トークンから継承し、保存エラー等の文字色も同じフォールバックに対応した。明色・暗色・システムの明暗・Mattermostの5通りで、表のAPIパス、時間、見出し、フィルター、エラー詳細の通常文字コントラストが4.5以上になることを確認。

## 説明と状態

- 「Deckを開いたとき、前回のメンションを先に表示する」「その間に最新の投稿を取得する」という利用結果を説明する。前回表示がない場合の動作も明記。
- 説明を9言語で更新し、保存方式やレート上限等の内部仕様を通常の説明から除去。
- 前回表示に専用のオン／オフ操作を設け、オン／オフと保存済み／未保存を文字で表示する。動作タブの同じ設定と連動。
- 取得待ちを短くするプリセットは別の操作に分離。適用済み・未適用・保存待ちを表示し、前回表示のオン／オフを勝手に変更しない。

## フッター

二つの再現経路を確認した。

1. 注入されたページ倍率90%に対し、100vhの枠が縮み、約100pxの余白が残る。
2. 詳細へ移動する `scrollIntoView` が `overflow: hidden` のルートも94pxスクロールし、ヘッダーとフッターをずらす。

画面の上下端に固定したルートへ変更し、本文・サイドバー以外の枠は `overflow: clip` とした。詳細選択・行展開後もルートのscrollTopが0、フッター下端が画面下端と一致することを実測した。
